# 图标设计说明

柔光拟态（Soft Neumorphism）／触感极简（Tactile Minimalism）。

## 一句话

一块被左上方光照到的哑光材料，上面压出一根分成两支的管子，分叉处落着一颗小小的深色节点。
没有描边、没有发光、没有渐变网格，体积完全由明暗过渡塑造。

## 形体

- 底座：圆角方块，圆角半径 = 边长 × 0.228（连续圆润，没有硬边）。
- 主体：一根竖管在分叉点分成两支，管径 136（设计坐标 1024），分叉处的节点略粗于管径（r 86），
  形成"很轻的凸起"，而不是贴上去的装饰。
- 分叉点以下保留一小段主干：读起来是"从主线分出去的一条支"，而不是字母 Y。
- 整枚图标只有一个视觉焦点（节点），四周留白充足。

## 光

- 全图只有一个光源，固定在左上（圆心 26%, 20%），向外缓慢衰减到零，边缘自然消失。
- 边缘倒角：左上一道极淡的高光（白 50%），右下一道更淡的暗部（棕 26%），不描边、不投影。
- 主体与节点各有一层柔和投影，方向与光源一致（右下），不堆叠多重投影。

## 材质与色彩

| 用途 | 值 |
|---|---|
| 材料本色（上 → 下） | `#E8E6DF` → `#C6C2B8` |
| 主体（上 → 下） | `#FBFAF6` → `#E5E2D9` |
| 阴影 | `#787060`（低透明度，阴影里带环境色） |
| 点缀 | `#687694` / 暗部 `#4E5A74` |

- 低饱和、近单色，只靠明度拉层次；唯一的彩色元素是分叉处的节点（面积 < 6%）。
- 不用纯黑纯白：最亮处是 `#FFFAF2` 的柔光，最暗处是暖棕而不是黑。

## 自适应图标

- 背景层：`drawable/ic_launcher_background.xml`，一层竖向渐变 + 一团左上柔光，颜色与本文档一致。
- 前景层：`mipmap-*/ic_launcher_foreground.png`（108dp 画布，主体占 56%，留在安全区内）。
- 单色层：`drawable/ic_launcher_monochrome.xml`，Android 13+ 主题图标用，只有轮廓。

## 重新生成

```bash
python3 scripts/dev/generate-icon.py
```

脚本只依赖 Pillow，输出前景 PNG（mdpi…xxxhdpi）、`docs/icon-512.png`（商店 / README）与
`docs/icon-preview.png`（192/96/72/48 自检）。

改配色只改脚本顶部的常量，并同步 `ic_launcher_background.xml` 的渐变（两处必须一致，
否则桌面上的背景与商店图会对不上）。

## 验收

- 缩到 48px 仍能认出"分叉 + 一个节点"的轮廓，不依赖细节。
- 桌面上与系统图标并列时不刺眼，但能凭轮廓找到。
